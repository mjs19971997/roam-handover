# ns-3 scenario: ROAM against tuned Event A3

Source of the scenario program (`ho-scenario.cc`, for ns-3.48 with the 5G-LENA `nr` module
v5.1, built natively on Windows), the scripts that install the tool chain and build the program
(`setup/`, `fix_srs.sh`, `build_scenario.sh`) and the scripts that start the runs
(`campaign.py`, `run_study.py`).

The description of the files, the installation and the run commands is in
[`../README.md`](../README.md), section "Building and running the scenario"; the study plan is
[`../PLAN.md`](../PLAN.md). The runs of the paper are in `../results/`.
